# 旅行用割り勘アプリ 仕様書

## 確定した仕様

### 均等割りの端数処理

- 国内旅行の金額は1円単位の整数として扱う。
- 1人あたりの基本負担額は、総費用を参加者数で割って切り捨てる。
- 割り切れずに余った金額は、参加者の登録順に1円ずつ割り当てる。
- 各参加者の負担額の差は最大1円とする。

例として、10,001円を3人で割る場合は次の負担額になる。

- 登録順1人目：3,334円
- 登録順2人目：3,334円
- 登録順3人目：3,333円

この方法を採用する理由は次のとおり。

- 全員の負担額の合計と総費用が必ず一致する。
- 同じ入力なら毎回同じ結果になり、動作を説明しやすい。
- 参加者間の負担差を1円以内に抑えられる。

ここで決めるのは各参加者の最終的な負担額である。
実際に誰が誰へ送金するかは、それまでに各参加者が支払った金額との差から別途計算する。
